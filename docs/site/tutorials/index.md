# Tutorials

Each tutorial walks you through one real job from start to finish using the sample organization that ships with Marula. If you just need a quick checklist for a daily task, jump to [How-to guides](../how-to/index.md). If you want field definitions or API details, check [Reference](../reference/index.md). If you want the reasoning behind a product rule, read [Explanation](../explanation/index.md).

Every tutorial lists its target **Audience** (`both`, `admin`, or `developer`) and what you need open before you begin.

Not sure which one? [Start here](../start/index.md) routes by role. When something is broken rather than unfamiliar, use [Troubleshooting](../troubleshooting.md).

- [Your first ticket](first-ticket.md) — **For technicians and service desk leads.** Pick up an open ticket from the morning queue, start the timer, write a note, and stop the clock so your work lands in the billing approval queue. ([API edition](first-ticket-api.md) runs the same steps with `curl`.)
- [Your first invoice](first-invoice.md) — **For office managers and bookkeepers.** Take approved technician hours, verify the billing window against a client contract, sign off on the numbers, and issue an invoice.
- [Portal onboarding](portal-onboarding.md) — **For service desk leads and admins.** Choose which ticket boards a client can see, create a portal login for their point of contact, and walk through what the client sees when they sign in.
- [Your first inventory sync](first-inventory-sync.md) — **For technicians and admins.** Connect an RMM or asset source, review incoming computers in the merge queue so you don't create duplicates, and attach a managed device to its client record.
- [Your first agent run](first-agent-run.md) — **For admins.** Enroll an AI assistant, require it to show you a step-by-step plan before touching any ticket, run it once under your supervision, and inspect its audit trail.
