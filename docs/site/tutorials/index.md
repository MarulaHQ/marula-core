# Tutorials

A tutorial is a learning-oriented lesson: one concrete path, worked end to
end, with everything the learner needs along the way. Tutorials do not
catalog options (that is [reference](../reference/index.md)) and do not argue
design (that is [explanation](../explanation/index.md)). Every tutorial
carries an **Audience** tag and a prerequisites block — check the tag
(admin / user / both) and the prerequisites before starting.

- [Your first ticket](first-ticket.md) — in the console: from the seeded
  demo org's work queue through the workbench to an approved, billable
  time entry.
  [API edition](first-ticket-api.md) for the same lesson against the
  real endpoints.
- [Your first inventory sync](first-inventory-sync.md) — connector →
  merge queue → device → asset → client link.
- [Your first invoice](first-invoice.md) — approved time → billing run →
  issued invoice → corrections the honest way.
- [Your first agent run](first-agent-run.md) — the seven-step agent
  ladder, plus turning one AI surface on for one role.
- [Portal onboarding](portal-onboarding.md) — provision a portal user,
  expose boards, and the client's first sign-in and request.
