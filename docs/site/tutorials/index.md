# Tutorials

A tutorial is a learning-oriented lesson: one concrete path, worked end to
end, with everything the learner needs along the way. Tutorials do not
catalog options (that is [reference](../reference/index.md)) and do not argue
design (that is [explanation](../explanation/index.md)).

- [Your first ticket](first-ticket.md) — run the stack, register an org, work
  a ticket through to a time entry.
