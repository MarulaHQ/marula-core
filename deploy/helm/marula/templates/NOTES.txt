IMPORTANT before installing beyond an evaluation:

- {{ if .Values.existingSecret }}Using existingSecret "{{ .Values.existingSecret }}".{{ else }}A Secret was generated from inline values — set secrets.jwtSecret and
  secrets.appSecretKey (envelope encryption for BYOK/webhook/connector
  secrets) before real use.{{ end }}
- Images are digest-pinned per release policy: set images.*.digest from the
  release's published SBOM/provenance attestations (digestPinningEnforced).
- Set images.web.nextPublicApiUrl (web.nextPublicApiUrl) to the URL your
  BROWSER uses to reach the API; it is baked into the client bundle.
- With it, set web.nextPublicWsUrl (wss://<host>/ws) — the realtime socket
  is baked the same way, and the client's fallback derivation points at the
  raw port 8081 that an ingress does not publish.
- Behind an edge proxy or CDN, set coreApi.trustedProxies to the edge's
  published ranges AND the ingress controller's, so the real-client walk can
  skip both hops (docs/site/reference/reverse-proxy-tls.md).
- Migrations run automatically as a pre-upgrade hook; the chain is
  forward-only. Run `marula upgrade --check` against a DB copy + manifest
  before upgrading (docs/upgrade-compatibility-policy.md §5/§7).
