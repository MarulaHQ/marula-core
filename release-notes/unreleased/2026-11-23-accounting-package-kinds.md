### Added

- The accountant package now carries vendor bills, a stock valuation at period end and e-waste dispositions, each with a stable reference back to its Marula record. The same period is available as a CSV file for an organisation with no accounting connection. If a reporting class in the period has no account, the package holds and names the classes instead of posting to a guessed account; set one in Class accounts and read it again.
