# filter-repo replacement expressions for the committed agent-config secret.
#
#   git filter-repo --replace-text scripts/purge-secrets-expressions.local.txt
#
# The real pattern is NOT committed: a file that names the secret to remove is
# itself a copy of the secret. On the machine that needs it, create the
# ignored file `scripts/purge-secrets-expressions.local.txt` containing one
# line, using the regex form so the token's trailing `==` padding cannot be
# mistaken for filter-repo's `==>` separator:
#
#   regex:<first 22 chars of the token, + escaped>={2}==>REDACTED-BEARER-TOKEN
#
# filter-repo treats every line as `literal==>replacement` and splits on the
# FIRST `==>`; a token ending in `==` therefore needs the regex form above, or
# the split eats the padding and only matches where a space follows.
#
# Removing the files is not enough on its own: the security audit's own
# evidence quoted the literal. --replace-text is what scrubs those blobs.
