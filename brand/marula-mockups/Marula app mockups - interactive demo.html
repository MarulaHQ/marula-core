Field tech app

Tap through a visit: start travel, open the job, tick the checklist, then wrap up with a signature. Tap the offline banner to go back online.

Things to try

Ticket header

  • Click any status step to set it. New, In progress, Waiting, Resolved.
  • Use the chips above the timeline to filter activity.

Composer

  • Switch between Reply to client and Internal note. The colour, visibility label and button change.
  • Send with the button or ⌘/Ctrl + Enter.
  • With Set to Waiting after send ticked, a client reply moves the ticket to Waiting.

Assistant

  • Run profile reset script logs the run in the timeline.
  • Not this dismisses the suggestion, with an undo.
  • Tap a suggestion chip or ask a question; the answer lands in the timeline.

Timer bar

  • Pause and resume the timer.
  • Type a line in the note field and press Enter to add it to your notes.
  • The arrow button opens all your note lines. Click a line to edit it.

Wrap up

  • Notes are built from your note lines.
  • Pick an outcome and watch the main button's label change.
  • Resolve to add the time entry, update the status and see what opens next.

Shortcuts

Today

  • Tap Start travel, then I've arrived. It opens the job and switches the timer.
  • Tap the offline banner to go back online, and again to go offline.
  • The call, directions, scan and photo buttons show what they'd do.

On site

  • Tick checklist steps and watch the count and the drafted notes update.
  • Wrap up opens the finishing screen.

Wrap up

  • Choose an outcome; the main button's label follows.
  • Sign in the box with your mouse or finger. Clear resets it.
  • Resolve and sync returns you to Today. While offline, the queued changes count goes up.

Anywhere

  • Use the panel beside the phone to jump to any screen.
  • Switch themes at the top; the phone updates live.
