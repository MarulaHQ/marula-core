# connectors

> **Purpose:** First-party HTTP connectors (Apache-2.0): NinjaOne, Hudu, IT Glue, ImmyBot, Auvik (webhook-first), QBO, Xero, M365 Graph, **DMS sync (IT Glue / Hudu exports + generic REST, 2026-09-10)**. Reference implementations of the connector pattern.
> **Non-purpose:** No hosted OAuth apps, credential vaulting, or sync-monitoring operations — hosting/operating connections commercially is out of scope for this repo. Every adapter documents its none-mode.
